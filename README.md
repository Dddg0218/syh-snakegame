# 贪吃蛇 · 网页版

邵逸煌做的网页小游戏，原生 Canvas 实现，没有框架、没有依赖。

## 玩法

- **移动**：方向键 / WASD / 手机滑动
- **暂停**：空格
- **目标**：吃果实变长，躲开石墙、NPC 蛇和自己的尾巴

## 机制

| 元素 | 说明 |
| --- | --- |
| 石墙 | 随机生成的障碍，撞上直接结束 |
| NPC 蛇 | 蓝色 / 橙色的电脑蛇，会追你，撞上也算输 |
| 金色道具 | 长度翻倍，分数 +25 |
| 蓝色道具 | 减速 6 秒，好过弯 |
| 紫色道具 | 无敌 6 秒，可以穿墙穿过 NPC |
| 青色道具 | 长度减半，分数 +15 |
| 关卡 | 每吃 5 个果实升一关，石墙和 NPC 变多 |

## 文件

- `index.html`：页面结构
- `web-game.css`：样式
- `web-game.js`：游戏逻辑（含渲染循环、NPC AI、道具系统）

## 本地运行

直接双击 `index.html` 就能玩，也可以起个静态服务器：

```bash
python -m http.server 8000
```

最高分存在浏览器 localStorage 里，键名 `syh-snake-best-v2`。
