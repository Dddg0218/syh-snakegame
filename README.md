# 贪吃蛇 · 网页版

邵逸煌做的网页小游戏，原生 Canvas 实现，没有框架、没有依赖，音乐也是用 Web Audio 现场合成的。

## 玩法

- **移动**：方向键 / WASD / 手机滑动
- **暂停**：空格
- **冲刺撕咬**：Shift（3 格无敌，撞到 NPC 直接咬死，冷却 4.2 秒）
- **蛇蜕陷阱**：E（留下一段身体当陷阱，NPC 撞上会死，冷却 7.2 秒）

## 机制

| 元素 | 说明 |
| --- | --- |
| 石墙 | 随机生成的障碍，撞上直接结束 |
| NPC 蛇 | 会追你的电脑蛇；撞你身体它会死，你撞它身体你会死 |
| 金色道具 | 长度翻倍 |
| 蓝色道具 | 减速 6 秒 |
| 紫色道具 | 无敌 6 秒（可穿墙、穿 NPC） |
| 青色道具 | 长度减半 |
| 关卡 | 每吃 5 个果实升一关，石墙和 NPC 变多 |

## 两个原创设定

1. **冲刺撕咬**：把「只能逃」变成「可以反击」。冲刺期间无敌，穿过 NPC 会把它咬死并加分。
2. **蛇蜕陷阱**：用两节身体换一个陷阱，把 NPC 引过去撞死。是对「身体只是负担」这条老规则的改写。

## 声音

三首循环 BGM（CHILL / ARCADE / PULSE），全部用振荡器实时合成，没有音频文件；另有吃、升级、冲刺、击杀、死亡五组音效。开始页可切换曲目、开关音效。

## 文件

- `index.html`：页面结构（含难度 / 音乐 / 音效设置）
- `web-game.css`：样式
- `web-game.js`：游戏逻辑（渲染循环、NPC AI、道具、技能）
- `game-audio.js`：Web Audio 合成器
- `favicon.svg`：站点图标

## 本地运行

双击 `index.html` 就能玩，也可以起静态服务器：

```bash
python -m http.server 8000
```

最高分与设置存在 localStorage：`syh-snake-best-v3`、`syh-snake-settings-v3`。
